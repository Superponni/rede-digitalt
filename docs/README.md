# Dokumentasjon — start her

Rede Digitalt er nettversjonen av TOBBs medlemsmagasin Rede, live på **rede.no**. Her ligger alt vi har lært om hvordan prosjektet drives. Det er skrevet for både mennesker og Claude: les det før du gjør endringer.

## Ny i prosjektet?

1. **[kom-i-gang.md](kom-i-gang.md)** — tilganger, oppsett på egen maskin, og hvordan vi jobber sammen (miljøer, grener, publisering).
2. **[design/designsystem.md](design/designsystem.md)** — dagens farger, fonter, verktøykasse og designprinsipper vi har låst.
3. **[designkontrakt.md](designkontrakt.md)** — mal som fylles ut av designer + Asbjørn før redesign.

## Tre grunnregler

1. **Den trykte utgaven er fasit for tekst og bildevalg.** Ikke Word-filene, ikke råmappa. Designet på nett er fritt.
2. **Asbjørn tar de redaksjonelle valgene.** Vi foreslår, han godkjenner.
3. **Ikke kall noe ferdig før det er sett på både mobil og desktop** — og for innhold: sett på rede.no, ikke bare lokalt.
